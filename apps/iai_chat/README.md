# iai_chat

Application Flutter IAI-CHAT (UI).

## Setup plateformes

Si `android/` / `ios/` sont incomplets sur ta machine :

```bash
cd apps/iai_chat
flutter create --project-name iai_chat --org org.iai .
flutter pub get
flutter run
```
